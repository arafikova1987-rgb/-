# Мой стиль монтажа (Reels/Shorts)

Собрано по анализу 5 референсов (покадрово + по звуку: тайминги речи, паузы,
монтажные склейки). Это синтез — ни один приём, текст, лого или фраза
из референсов не копируются буквально.

## 0. Формат
Все 5 референсов — **говорю в камеру** (talking head), иногда со вставками
картинок/видео поверх. Стиль ниже рассчитан на этот формат.
*(Если у тебя часть роликов — закадровый голос, скажи: для него нужны
отдельные правила по монтажу планов и музыке.)*

## 1. Первые 3 секунды (хук)
- Речь стартует **с 0.00 сек, без разгона** — во всех референсах первое
  слово произносится в первом кадре.
- Текстовый хук-заголовок появляется на экране **в первые 0.1–0.6 сек**.
- Структура хука — 2–3 яруса текста: маленькая затравка → КРУПНОЕ ключевое
  слово → уточнение помельче. Либо прямой интригующий вопрос/цифра.
- Правило: к 3-й секунде зритель уже видит и текст, и понимает тему.

## 2. Темп речи и паузы
- Темп: **150–180 слов/мин** (в референсах разброс 139–199, беру середину
  под спокойную уверенную подачу, не скороговорку).
- Микропаузы между фразами: **0.3–0.6 сек** — используются как дыхание и
  смысловой разделитель, не как провисание.
- Пауза длиннее **1.5–2 сек тишины** — сигнал, что здесь нужна склейка или
  перебивка, а не воздух.

## 3. Монтажные склейки (длина планов)
- Базовый ритм: **новая склейка каждые 4–6 сек** — на каждую законченную
  мысль/фразу, не чаще.
- Для динамичных форматов (распаковка, быстрый юмор) можно уплотнять до
  **2.5–3 сек** на план.
- Для спокойного монолога (бизнес/экспертный рассказ) допустим один
  непрерывный дубль **10+ сек** без склеек вообще — это тоже рабочий приём,
  не обязательно резать часто.
- Резать строго **в микропаузах речи**, никогда посреди слова.

## 4. Субтитры
- **Шрифт:** Inter (кириллица есть на моей машине, во всех начертаниях) —
  `Inter ExtraBold`/`Inter Black` для акцентных слов, `Inter SemiBold` для
  обычного текста.
- **Размер:** крупный, вмещается в 2 строки на кадре 9:16; акцентное слово
  в **1.3–1.6 раза крупнее** обычного текста той же фразы.
- **Расположение:** нижняя треть кадра, отступ от нижнего края
  **8–10% высоты кадра**, не перекрывает лицо.
- **Появление:** слово/короткая фраза возникает **в такт произнесению**
  (word-by-word), без долгих fade — появление почти мгновенное (< 0.1 сек).
- **Подсветка слов:** один акцентный цвет на весь ролик для 1–2 ключевых
  слов во фразе (не на каждое слово).
- Без подложки/плашки под обычным текстом — только текст + тонкая тень для
  читаемости на любом фоне.

## 5. Цвета
- **Акцент (ключевые слова, бейджи, цифры):** `#B03A22` — терракотовый,
  уже используется в моих материалах (сценарии блога).
- **Базовый текст:** белый / `#F1F2F3`, с тонкой тёмной обводкой-тенью
  `#16181A` для контраста на любом фоне.
- **Тёмные плашки (если нужен бейдж под текст):** фон `#16181A`, текст белый.
- Один акцентный цвет на весь ролик — не смешивать несколько ярких цветов
  в одном кадре.

## 6. Графика и анимации
- Вставки (фото/мини-видео поверх кадра), плавающие бейджи-пилюли с
  перечислениями, бейджи-цифры (цены/факты) — используются, когда **несут
  информацию**, не просто для красоты.
- Скорость появления графики: **0.2–0.3 сек** на вход (slide/scale-in),
  не медленнее — иначе будет казаться тяжеловесным рядом с быстрыми
  субтитрами.

## 7. Цветокоррекция видео
- Чистый естественный свет, без тяжёлых LUT, без виньеток и зерна.
- Хорошая экспозиция, естественный тон кожи — цветокор только лёгкая
  коррекция контраста/баланса белого, не стилизация.

## 8. Музыка и громкость
- Голос всегда доминирует. Если есть музыкальная подложка — она тихая,
  примерно **на 20–25 дБ ниже голоса**, и не заглушает речь даже в паузах.
- В роликах с частыми резкими паузами в речи (без музыки) пауза уходит в
  полную тишину — это тоже нормальный вариант, если общий темп и так
  энергичный за счёт монтажа.

## 9. Что НЕ переносим (не копируем)
- Чужие лого, бренд-теги, подписи-кредиты ("ПТК:", водяные знаки).
- Чужие фирменные акцентные цвета, если они не совпадают с моей палитрой.
- Дословные фразы, шутки, формулировки хуков.
- Конкретные кадры/ракурсы/мизансцены один в один.
