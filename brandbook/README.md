# Бренд-бук Infinity Story

- `Infinity_Story_Brandbook.pptx` — презентация, 30 слайдов, для онбординга новых сотрудников (SMM, менеджеры маркетплейсов).
- `Infinity_Story_Brandbook_preview.pdf` — быстрый просмотр (рендер LibreOffice, шрифты подменены, в PowerPoint выглядит аккуратнее).
- `build/` — генератор (`build.js`) и картинки. Фото хитов кладутся в `build/photos/`, см. README там.

Источники: обучающее пособие сотрудника (docx), презентация Brand INFINITY STORY (pdf), бриф по контенту бренда.
