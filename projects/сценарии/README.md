# Сценарии для личного блога

`Сценарии-октября-Алёна.pdf` — готовый документ на 21 страницу: статус
сентябрьской съёмки, сценарий распаковки поставки и 14 сценариев на хуках
из гайда «100 хуков для Reels».

`Сценарии-октября.html` — исходник, из которого собран PDF.

## Пересобрать PDF

```bash
/opt/pw-browsers/chromium-*/chrome-linux/chrome \
  --headless --disable-gpu --no-sandbox --no-pdf-header-footer \
  --print-to-pdf="Сценарии-октября-Алёна.pdf" \
  "file://$PWD/Сценарии-октября.html"
```

Кириллица берётся из системного DejaVu Sans, внешние шрифты не нужны.

## Живые версии

Съёмочная карта сентября и словарь ключевых слов живут отдельными
артефактами и обновляются по ссылкам, выданным в переписке.
