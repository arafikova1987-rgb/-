Claude Code picks these up automatically — each subdirectory contains a
`SKILL.md` with `name` / `description` frontmatter, and the model loads a
skill when the task matches its description.

## Updating

```bash
git clone --depth 1 https://github.com/coreyhaines31/marketingskills.git /tmp/ms
rm -rf .claude/skills/*/
cp -r /tmp/ms/skills/. .claude/skills/
```
